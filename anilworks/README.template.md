# Anilworks

Personal **work context** for Applaud features and bugs. Used by the `anilworks-context` skill so new chats can resume without re-discovery.

- One markdown file per ticket (or tight thread).
- No secrets in git — redact tokens; use env var names only.
- Prefer updates here over long chat-only history.
